# Personalized Webpage

## Description
This project collects a user's name and age, stores the information in localStorage, and displays personalized content.

## Features
- User input form
- localStorage data persistence
- Personalized greeting using template literals
- Age calculation in months
- Adult content eligibility check using if...else
- Motivational quote displayed 5 times using a loop
- Responsive CSS design

## Technologies Used
- HTML
- CSS
- JavaScript
- localStorage

## How to Run
1. Download the files.
2. Open index.html in a browser.
3. Enter your name and age.
4. View personalized content.

## Deployment
Deploy using GitHub Pages.
